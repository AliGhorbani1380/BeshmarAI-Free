# قرص شمار | BeshmarAI Free

نسخه عمومی، رایگان و مستقل قرص شمار برای انتشار ایستا روی GitHub Pages.

## معماری نهایی

- وب‌سایت اصلی: `https://beshmarai.ir/`
- برنامه شمارش: `https://beshmarai.ir/app/`
- پردازش تصویر و اجرای مدل روی دستگاه کاربر
- بدون backend، پایگاه داده، حساب کاربری، OTP، پرداخت یا اشتراک
- بدون پنل مدیریت و بدون ارسال تله‌متری به سرور خصوصی
- بدون ارسال تصویر شمارش به سرور
- انتشار سایت و برنامه از یک مخزن عمومی مستقل

## مدل‌های عمومی

فایل‌های خام مدل در آرشیو Source قرار ندارند. اسکریپت آماده‌سازی Stage 2 دو
مدل را با اندازه و SHA-256 دقیق بررسی می‌کند، مدل دقیق را به چهار قطعه حدود
۲۰ مگابایتی تقسیم می‌کند و `manifest.json` را می‌سازد.

قراردادهای مورد انتظار:

- Preview: `2,674,908` بایت
- Final 1152 FP32: `80,805,153` بایت

قطعه‌ها در مسیر زیر قرار می‌گیرند:

```text
apps/web/public/models/public-v1/
```

## Build محلی

پس از ساخته‌شدن بسته مدل:

```powershell
npm run install:all
npm run typecheck
npm run build
```

خروجی نهایی GitHub Pages در `deploy/` ساخته می‌شود. وب‌سایت در ریشه و برنامه
Vite/PWA در `deploy/app/` قرار می‌گیرد.

## کنترل‌های انتشار

```powershell
npm run verify:public
npm run verify:models
```

Workflow موجود در `.github/workflows/pages.yml` همین کنترل‌ها، TypeScript و
Build کامل را پیش از انتشار اجرا می‌کند.

## امنیت و جداسازی

هیچ رمز، کلید API، فایل `.env` واقعی، backend، پایگاه داده، OTP، پرداخت، پنل
مدیریت یا تاریخچه Git مخزن خصوصی نباید وارد این مخزن شود. ساخت این نسخه نباید
ریپوی خصوصی را تغییر دهد.

## حقوق

Public بودن این مخزن به‌تنهایی مجوز استفاده، فروش، تغییر یا بازتوزیع ایجاد
نمی‌کند. تا زمانی که فایل مجوز جداگانه‌ای افزوده نشده، همه حقوق محفوظ است.
