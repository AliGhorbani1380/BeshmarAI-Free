## ویژگی‌های نسخه عمومی

- **انگلیسی پیش‌فرض و فارسی با یک لمس**؛ سایت فارسی در `/fa/` و انتخاب زبان برنامه در حافظه مرورگر ذخیره می‌شود.
- **انتخاب خودکار، GPU یا CPU**؛ حالت خودکار توان دستگاه را یک‌بار می‌سنجد و کاربران حرفه‌ای می‌توانند WebGPU یا WebAssembly و تعداد رشته CPU را انتخاب کنند.
- **شمارش دقیق قابل بررسی**؛ نتیجه همراه نشانه‌های تشخیص نمایش داده می‌شود.
- **حریم خصوصی در معماری**؛ حساب کاربری، شماره موبایل، OTP، اشتراک، API خصوصی inference و ارسال تصویر وجود ندارد.
- **PWA قابل نصب**؛ فایل‌های برنامه و قطعات مدل برای استفاده‌های بعدی Cache می‌شوند.
- **بازگشت امن**؛ در صورت ناسازگاری GPU، مسیر پایدار CPU در دسترس است.

## استراتژی اجرا

| حالت | کاربرد | رفتار |
|---|---|---|
| **خودکار** | پیشنهادشده | سنجش دستگاه و ذخیره بهترین برنامه پایدار |
| **GPU / WebGPU** | دستگاه‌های مدرن سازگار | اجرای WebGPU با بازگشت امن به CPU |
| **CPU / WebAssembly** | بیشترین سازگاری | اجرای ۱، ۲ یا ۴ رشته‌ای در صورت پشتیبانی |

## ساختار مخزن

```text
apps/site   سایت استاتیک Next.js با انگلیسی در / و فارسی در /fa
apps/web    برنامه دوزبانه Vite + React برای شمارش قرص
scripts     بررسی مرز عمومی، صحت مدل و Build گیت‌هاب پیجز
```

## اجرای محلی

```bash
npm ci --prefix apps/site
npm ci --prefix apps/web
npm run typecheck
npm run build
```

## مرز امنیتی نسخه عمومی

این مخزن عمداً شامل موارد زیر نیست:

- Backend و پایگاه داده خصوصی
- ورود شماره موبایل و OTP
- پرداخت، اشتراک و پنل مدیریت
- Credentialهای پروداکشن و فایل واقعی `.env`
- Telemetry خصوصی
- تاریخچه Git مخزن خصوصی

## هشدار ایمنی

قرص شمار یک **ابزار کمکی** است. هم‌پوشانی قرص‌ها، نور، فوکوس، بازتاب، سخت‌افزار دوربین، مرورگر و توان دستگاه می‌توانند روی نتیجه اثر بگذارند. هر نتیجه باید توسط کاربر مسئول بررسی و تأیید شود. برنامه دارو را شناسایی نمی‌کند، نسخه نمی‌نویسد و جایگزین رویه‌های حرفه‌ای داروخانه نیست.

## حقوق

Public بودن مخزن به‌تنهایی مجوز استفاده، فروش، تغییر یا بازتوزیع ایجاد نمی‌کند. تا زمانی که فایل مجوز جداگانه‌ای اضافه نشده، همه حقوق محفوظ است.
